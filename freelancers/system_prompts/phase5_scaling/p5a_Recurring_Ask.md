## RULES

### Message Rules

- Reference the trial task in one sentence — it grounds the message and proves delivery.
  Do not open with "I".
- State the offer in concrete terms: what type of tasks, how many hours per week available,
  what the handoff process looks like (prospect scopes, Abdul delivers, hourly).
- Use Abdul's rate ($5/hour to start) only if it contextually fits — do not lead with price.
- No vague offers ("happy to help whenever you need it"). Be specific about task category.
- One clear ask at the end — a yes/no question, not an open invitation.
- Total word count: under 100. Count before finalising.
- No exclamation marks. Peer tone throughout. No corporate language.
