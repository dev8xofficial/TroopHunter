I just built a fully functional programming language in 8 days.




 ...using only Claude Code and a clear idea of what I wanted.

 • Lexer that tokenizes input
 • Parser that builds ASTs
 • Interpreter that evaluates code
 • Type checker, error handling, REPL
 • All written in Go

 The result? EZ, a statically-typed language built on one idea: simple for beginners, powerful for experts.

 No classes. No objects. No implicit behavior

 The framework that made this possible:
 1. Document your vision FIRST (before any AI conversations)
 2. Use context files, not chat history
 3. Invite criticism — let the AI push back on bad ideas
