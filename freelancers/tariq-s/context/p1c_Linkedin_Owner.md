On the day React 19 was released, I had my eyes and ears open, and so did most of you. However, many are missing one significant aspect of the changes in the newest version of React, which will change how you write and develop applications.

What seemingly everyone was talking about throughout the day, when React 19 was released, was that Server Components were now stable and could be included in projects without worrying about breaking changes. This was a major focus of discussion. The most useful feature is the new `use()` hook and how it handles asynchronous data.

Before React 19, if you had a component that was going to read a Promise, you would have had the headache of writing out useEffect, useState, handling loading state, and error state on every single call to that Promise. Now you can simply write:

```
const data = use(fetchUserData(userId));
```

With React Suspense handling loading state and Error Boundaries handling failures, the mental overhead of writing data fetching logic has decreased drastically.

Notable components of React 19:
1. Actions — native way to handle asynchronous mutations with a built-in pending/error state for forms
2. useFormStatus and useOptimistic — build fast-feeling applications without an additional state management library for most forms
3. ref is finally treated just like a normal prop — no more forwardRef boilerplate
4. The compiler (React Forget) is finished — useMemo/useCallback no longer needed for most instances

I've been migrating a mid-sized Next.js 15 app, and the reduction in ceremony is real.
