## Step 1 — Three-Level Spatial Map

Spatial rhythm exists at three distinct levels. Measure each
independently — do NOT conflate them.

**Level A — Page / Section Gaps**
The space between major layout regions (e.g., header to main content,
one section to the next scrollable section). Read the route page and
top-level component composition for these values.
  - Value: [px from token/class] — [confidence]

**Level B — Component-to-Component Gaps**
The space between adjacent cards, modules, or tiles within a section
(i.e., grid gutters). This is NOT the same as Level A. Read grid and
flex gap values in component files.
  - Value: [px from token/class] — [confidence]
  - Note: Some designs use near-zero gaps (2–8px) to create a
    "seamless surface" effect — cards read as a fused panel rather
    than individual tiles. Flag this if present.

**Level C — Intra-Component Padding**
The space inside individual cards and components — between the edge
of the container and its internal content. Read padding classes on
component root elements.
  - Value: [px from token/class] — [confidence]

**Outer-to-Inner Ratio**
Express the ratio from Level A to Level C as a proportion.
  Example: "32px (section) to 16px (card interior) = 2:1"
