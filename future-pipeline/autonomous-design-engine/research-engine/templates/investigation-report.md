# Investigation Report — `<A-id>` — `<date>`

> The full record of one Area's investigation. The appendix behind the Decision Records. Long is fine here; the one-page artifact humans act on is the Decision Record.

---

## Provenance header (for auditability — [`../06 §6`](../06-governance-and-integrity.md))
- **Area / Area Card version:** `A-...` @ `<hash/date>`
- **Mode:** paper / empirical / mixed
- **Proportionality tier:** Light / Standard / Deep
- **Perspectives & substrate:** e.g. Reconstructor=Opus, Attacker=Sonnet (fresh ctx), domain lens=`evaluation`
- **Context fed in:** which spec docs / failure files / KB entries
- **Divergence prompt used:** `<verbatim or link>`

## 1. Frame
The question behind the asked question. What a good answer would let ADE do differently.

## 2. Reconstruction
How the area works, rebuilt from first principles. Discrepancies vs. the spec.

## 3. Divergence output (unbounded)
The full generated set — every question/hypothesis/attack/analogy. (These all become Backlog entries; none discarded — [`../01 §4.3`](../01-operating-model.md).)

## 4. Convergence — EVI ranking
Table: item · impact · probability · reversibility · cost · **EVI** · picked-now? / backlogged.

## 5. Pre-registration
What we expected to find, recorded *before* investigating (bias check — [`../06 §3`](../06-governance-and-integrity.md)).

## 6. Investigation per picked item
For each: evidence gathered (supporting **and** contradictory), instrument used, tier reached.

## 7. Adversarial pass
For each surviving claim: what was tried to falsify it, and whether it survived. The falsification condition ("what would change our mind").

## 8. Steelman of the status quo
The strongest case for changing nothing. (Mandatory before any change recommendation.)

## 9. Findings
Each finding: claim · Evidence tier · confidence (≤ cap) · support · falsifier · affected Areas.
Distinguish: confirmed / probable / unresolved / unexpected. Note any **null results** explicitly.

## 10. Decision Records produced
Links to the one-page records ([`decision-record.md`](./decision-record.md)).

## 11. Backlog changes
New items added, items promoted, items closed (with reasons).

## 12. Recorded end state
`Decided` / `Deferred` / `Inconclusive` — and the Area's new Registry status.
