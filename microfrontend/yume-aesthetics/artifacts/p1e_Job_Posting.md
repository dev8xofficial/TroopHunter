# WordPress Website for Premium Skin Clinic (SEO + High-End Design) — Yume Aesthetics — Job Posting

## Role Summary

Yume Aesthetics is a premium, results-driven skin clinic based in Sydney specialising in extraction facials, chemical peels, skin needling, and advanced laser and light therapies. They are looking for an experienced WordPress designer/developer to create a clean, high-end, and conversion-focused website that positions the clinic as premium, attracts new local clients through SEO, and converts visitors into bookings. The client will provide branding, content direction, service information, and design inspiration references (attachments included in the posting).

## Responsibilities

- Design and develop a fully responsive WordPress website.
- Create a clean, modern, and premium aesthetic (aligned with provided inspiration) featuring a soft, cool-toned neutral palette (white, black, taupe tones) to achieve a calm, clinical yet welcoming feel.
- Build key pages: Home, About, Services (with individual service pages if needed), Skin Concerns / Treatment Guide, and Contact / Booking.
- Integrate a booking system (Fresha or external booking link).
- Ensure fast loading speed, mobile optimisation, and easy navigation that is focused on trust, results, and education.
- Implement on-page SEO optimisation for a local skin clinic in Sydney, including optimised page structure, headings, metadata, and keyword integration (e.g., skin clinic Sydney, skin needling Sydney, acne treatment Sydney).
- Setup basic local SEO, including Google-friendly structure and schema if possible.
- Perform image optimisation and site speed optimisation.
