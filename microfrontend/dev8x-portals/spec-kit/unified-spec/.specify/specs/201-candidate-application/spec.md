# Candidate Application Timeline
> **Module ID**: `201-candidate-application`
> **Domain**: Candidate Portal (2xx)
> **Version**: 1.0.0

---

## Overview

A multi-step vertical timeline showing the candidate's journey: Application Submitted -> AI Screening -> Shortlisted -> Interview Scheduled -> Interview -> HR Review -> Offer/Not Selected.

---

## Functional Requirements

### FR-201-01: Timeline Rendering
- [ ] Display steps with states: done, current, pending, skipped
- [ ] Expandable detail panels per step (e.g., AI screening feedback)
