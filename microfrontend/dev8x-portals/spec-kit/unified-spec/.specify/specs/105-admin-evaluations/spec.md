# Admin Evaluations
> **Module ID**: `105-admin-evaluations`
> **Domain**: HR Admin Panel (1xx)
> **Version**: 1.0.0

---

## Overview

Provides a structured scoring grid and checklist for applicant assessment. Supports multi-dimension ratings (e.g., technical, cultural) to calculate an aggregate score.

---

## Functional Requirements

### FR-105-01: Scoring Grid
- [ ] Define customizable rating dimensions per job
- [ ] 1-5 star rating interface for each dimension
- [ ] Calculate aggregate score

### FR-105-02: Assessment Checklist
- [ ] Yes/No checklist for standard requirements
- [ ] Attach text notes to evaluation

### FR-105-03: Evaluation History
- [ ] List all evaluations submitted for a candidate
- [ ] Display aggregate score on Applicant Detail profile
