# Admin Interviews
> **Module ID**: `104-admin-interviews`
> **Domain**: HR Admin Panel (1xx)
> **Version**: 1.0.0

---

## Overview

Manages the interview scheduling process. HR Admins can define available time slots, assign interviewers, and match candidates to slots. Integrating with the candidate portal for self-scheduling.

---

## Functional Requirements

### FR-104-01: Interview Scheduling
- [ ] Create interview event linked to an applicant
- [ ] Define date, time, and duration
- [ ] Assign interviewer(s)
- [ ] Specify type (Phone, Video, On-site)

### FR-104-02: Calendar View
- [ ] Display scheduled interviews on a calendar
- [ ] Highlight conflicts
- [ ] Show availability slots

### FR-104-03: Interview Status
- [ ] Track status: Scheduled, Completed, Cancelled, No-Show
- [ ] Trigger notifications on status changes
