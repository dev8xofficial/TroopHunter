# Candidate Dashboard
> **Module ID**: `200-candidate-dashboard`
> **Domain**: Candidate Portal (2xx)
> **Version**: 1.0.0

---

## Overview

The landing page for candidates. Displays an overall progress tracker (%), current application status, upcoming deadlines with priority indicators, and quick action buttons.

---

## Functional Requirements

### FR-200-01: Progress Tracker
- [ ] Display overall completion percentage
- [ ] Show current step in the application timeline

### FR-200-02: Deadlines & Actions
- [ ] List upcoming deadline items with priority dots (red/orange/green)
- [ ] Action buttons: Upload Document, Message HR, Schedule Call
