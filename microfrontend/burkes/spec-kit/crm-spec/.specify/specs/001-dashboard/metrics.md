# Success Metrics: CRM Dashboard (001)

| KPI | Target | Alert |
| --- | --- | --- |
| Dashboard load time (p50) | < 2s | > 4s |
| Click-through success rate | > 99% | < 95% |
| Summary freshness lag | < 60s | > 5m |
| Empty-state confusion reports | 0 critical | Any repeated support issue |

## Success Definition

Dashboard is successful when operators routinely use it to enter the right next workflow without relying on separate legacy tools for situational awareness.
