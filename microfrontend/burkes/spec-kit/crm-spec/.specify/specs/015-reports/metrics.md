# Success Metrics: CRM Reports (015)

| KPI | Target | Alert |
| --- | --- | --- |
| Report load time for default views | < 3 sec | > 6 sec |
| Drill-down usage from KPI modules | > 35% | < 15% |
| Metric freshness within expected SLA | > 95% | < 85% |

## Success Definition

Reports is successful when leaders can answer operational performance questions directly in the CRM and move from a number to the underlying work without resorting to separate spreadsheets.
