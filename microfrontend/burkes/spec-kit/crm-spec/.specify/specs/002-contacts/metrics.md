# Success Metrics: CRM Contacts (002)

| KPI | Target | Alert |
| --- | --- | --- |
| Contact create time | < 60s for minimal create | > 2m |
| Duplicate creation rate | < 1% | > 3% |
| Import exception rate | < 5% | > 15% |
| Missing-data backlog aged > 7 days | < 10% of active contacts | > 25% |

## Success Definition

Contacts is successful when operators can rely on one directory for creation, lookup, and enrichment without falling back to legacy CRM records.
