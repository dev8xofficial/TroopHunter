# Rollout Plan: CRM Foundation

- Roll out internally to platform admin and department owners first.
- Validate navigation, quick actions, and permission visibility before enabling broader operator use.
- Gate portal-intake notifications behind an internal flag until duplicate-safe handling is verified.
- Validate install prompt visibility and installed-session messaging on supported mobile and tablet browsers before broader rollout.
- Roll back by disabling shell bootstrap if shared contracts cause cross-screen regressions.
