# Success Metrics: CRM Foundation (000)

| KPI | Target | Alert |
| --- | --- | --- |
| Shell load time (p50) | < 1.5s | > 3s |
| Quick-action open latency | < 400ms | > 800ms |
| Notification delivery latency | < 5s | > 30s |
| Permission mismatch rate | 0 critical defects | Any production-critical issue |
| Install prompt eligibility success | > 95% | < 85% |

## Success Definition

Foundation is successful when all CRM features inherit one shell and one access model without requiring local overrides for core behavior, while eligible devices can discover the supported installed experience.
