# Changelog — Agent Portal Spec-Kit

All notable changes to the spec-kit are documented in this file.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

---

## [1.0.0] — 2026-04-11

### Added

- **Foundation Spec (000)**: Design tokens, navigation, session context, activity log contract
- **Dashboard Spec (001)**: KPI stat cards, quick actions, upload zone, active transactions table, activity feed
- **Transactions Spec (002)**: Transaction list, filtering, Create Transaction modal, View Transaction modal, Update Stage modal
- **Documents Spec (003)**: Document upload, categorisation, assignment to transactions, filter/search
- **Clients Spec (004)**: Client profiles, Add Client modal, contact info, transaction links
- **Messages Spec (005)**: Inbox, compose message, multi-party communication, filter by sender type
- **Calendar Spec (006)**: Today's appointments, upcoming events, Schedule Appointment form
- **Partner Referrals Spec (007)**: Partner directory, search, ratings, referral submission form
- **Reports Spec (008)**: Sales KPIs, chart placeholders, transaction pipeline, quick reports, area analytics
- **Constitution**: 7 core principles, actor matrix, 12-stage lifecycle, reference data, design constraints
- **Templates**: 10 template files for specs, plans, tasks, changelogs, and supporting artifacts
- **Supporting Artifacts**: Complete changelog, validation-schema, test-scenarios, rollout, metrics, and risks for all 9 features
- **Governance**: STANDARDS, ARCHITECTURE, GLOSSARY, FAQ, ROADMAP, CONTRIBUTING, GOVERNANCE, CODE_OF_CONDUCT, SPEC-DRIVEN
- **GitHub Infrastructure**: CODEOWNERS, PR template, issue templates, CI workflows, Copilot prompts
- **Global Schemas**: spec-structure.json, activity-log-event.json, transaction-model.json
- **Decision Records**: ADR-001 through ADR-005
- **Research**: User personas, competitive analysis, constitution rationale, transition plan
