# Changelog — Service Partner Portal Spec-Kit

All notable changes to the spec-kit are documented in this file.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

---

## [1.0.0] — 2026-04-12

### Added

- **Foundation Spec (000)**: Design tokens, navigation, session context, activity log contract, badge system, button system
- **Dashboard Spec (001)**: KPI stat cards, new referral requests, service areas grid, recent reviews, quick actions
- **Referrals Spec (002)**: Referral list, status filtering, service type filtering, search, table with actions
- **Active Jobs Spec (003)**: Job cards, scheduling details, scope descriptions, contact/reschedule actions
- **Quotes Spec (004)**: Quote creation form, auto-total calculation, recent quotes, quote statistics
- **Reviews Spec (005)**: Review rating stats, review cards with star ratings, response management
- **Service Areas Spec (006)**: Active area grid, recommended areas, add area form, service area tips
- **Earnings Spec (007)**: Revenue hero card, KPI stats, payment history table with platform fees
- **Profile Spec (008)**: Business info form, service categories, notification preferences, account status
- **Constitution**: 7 core principles, actor matrix, 6-stage referral lifecycle, reference data, design constraints
- **Templates**: 10 template files for specs, plans, tasks, changelogs, and supporting artifacts
- **Supporting Artifacts**: Complete changelog, validation-schema, test-scenarios, rollout, metrics, and risks for all 9 features
- **Governance**: STANDARDS, ARCHITECTURE, GLOSSARY, FAQ, ROADMAP, CONTRIBUTING, GOVERNANCE, CODE_OF_CONDUCT, SPEC-DRIVEN
- **GitHub Infrastructure**: CODEOWNERS, PR template, issue templates, CI workflows, Copilot prompts
- **Global Schemas**: spec-structure.json, activity-log-event.json, referral-model.json
- **Decision Records**: ADR-001 through ADR-005
- **Research**: User personas, competitive analysis, constitution rationale
