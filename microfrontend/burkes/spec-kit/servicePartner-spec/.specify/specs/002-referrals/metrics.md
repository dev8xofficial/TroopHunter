# Metrics — Referrals
## Key Performance Indicators
| Metric | Target | Measurement Method |
|--------|--------|-------------------|
| Referral response time | <4 hours average | Track time between referral receipt and first action |
| Filter usage rate | >50% of sessions | Analytics on filter interactions |
| Referral conversion (lead→completed) | >70% | Status transition tracking |
## Monitoring
| Signal | Threshold | Action |
|--------|-----------|--------|
| Referral data fetch timeout | >3s | P1 alert to backend team |
| Missing referral status badge | Any occurrence | P0 visual bug |
