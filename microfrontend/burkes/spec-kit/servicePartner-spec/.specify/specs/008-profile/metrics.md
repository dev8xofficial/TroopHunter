# Metrics — Profile
## Key Performance Indicators
| Metric | Target | Measurement Method |
|--------|--------|-------------------|
| Profile completion rate | >95% | Count partners with all required fields filled |
| Profile update frequency | Monthly average | Track profile_updated events |
| Category coverage | >3 categories per partner average | Count selected categories |
## Monitoring
| Signal | Threshold | Action |
|--------|-----------|--------|
| Profile save failure rate | >1% | P1 alert to frontend team |
| Expired license numbers | Any detection | Admin notification for verification |
