# Changelog — Foundation

All notable changes to this specification are documented here.

## [1.0] — 2026-04-12

### Added

- Initial foundation specification with 7 functional requirements
- Design token system (colours, typography, shadows, spacing)
- Navigation bar contract with 8-screen switching and partner badge
- Session context definition with partner identity fields
- Canonical badge system for all referral/job/payment statuses
- Button system with 5 variants (primary, secondary, gold, success, table-action)
- Responsive layout breakpoint rules
- Activity log contract referencing global schema
