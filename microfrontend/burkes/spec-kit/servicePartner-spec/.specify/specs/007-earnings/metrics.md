# Metrics — Earnings
## Key Performance Indicators
| Metric | Target | Measurement Method |
|--------|--------|-------------------|
| Earnings data accuracy | 100% match with payment system | Automated reconciliation |
| Platform fee transparency | 100% of partners can see fee breakdown | UI audit |
| Pending payment resolution time | <7 days | Track awaiting→paid transition |
## Monitoring
| Signal | Threshold | Action |
|--------|-----------|--------|
| Earnings data mismatch | Any occurrence | P0 alert to finance team |
| Payment status stale | >30 days in "processing" | P1 alert to admin team |
