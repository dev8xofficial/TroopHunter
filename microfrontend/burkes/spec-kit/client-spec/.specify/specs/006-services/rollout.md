# Rollout Strategy: Services Spec

## Feature Flags

- `FF_SERVICES_ENABLED`: Enable services marketplace
- `FF_SERVICE_BOOKING`: Allow direct booking (default: false Phase 1)

## Success Criteria

✅ Service browse < 500ms
✅ Booking completion rate > 80%
✅ Provider satisfaction > 4.0 stars
