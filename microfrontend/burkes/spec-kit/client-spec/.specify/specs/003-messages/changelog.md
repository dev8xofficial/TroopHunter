# Changelog: Messages Spec

## [1.1.0] - 2026-03-15

### Added

- Message read receipts (blue checkmark)
- Thread blocking (mute notifications for specific users)
- Message search within transaction

## [1.0.0] - 2026-02-01

### Added

- Client-to-professional messaging
- Role-scoped recipients (attorney only sees attorneys in To: field)
- Notification on new message
