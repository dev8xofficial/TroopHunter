# Domain Glossary

| Term | Domain Concept Definition |
|---|---|
| **Transaction** | A stateful entity representing a property transfer contract mapping relationships between multiple principals. |
| **Document** | An immutable binary file representation coupled with cryptographic metadata. |
| **Referral** | A relational mapping token granting limited temporal access to an external attorney actor. |
| **Tenant** | Top level logical separation boundary for database multi-tenancy. |
| **Session** | Ephemeral authentication context carrying cryptographic identity signatures. |
