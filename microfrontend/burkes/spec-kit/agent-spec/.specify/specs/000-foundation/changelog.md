# Changelog: Foundation (000)

All notable changes to the Foundation spec.

---

## [1.0.0] — 2026-04-11

### Added

- Design token system: 16 colour tokens, typography (Archivo/Manrope), 4 shadow levels, spacing scale
- Global navigation bar: sticky top nav, 8 screen buttons, notification bell, user chip
- Session context contract: agent name, initials, role, brokerage, active transactions, unread count
- Activity log event contract: event_id, event_type, timestamp, actor_role, icon, label, description
- Badge system: 3 canonical variants (active, pending, completed)
- Card component: standard white card with 16px border-radius, shadow-md, 1px neutral-200 border
- Modal system: full-screen overlay for forms and detail views
- Filter section pattern: dropdowns + search bar + action button
- Upload zone: drag-and-drop file upload with supported formats
- Responsive breakpoints: ≥1200px (full), 768–1199px (reduced), <768px (mobile)
