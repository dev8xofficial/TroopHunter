## [1.0.0] — 2026-04-11

### Added

- KPI stat cards: Active Transactions, Pending Offers, This Month Sales, Commission Earned
- Quick Actions: Upload Agreement, Add New Listing, Create Offer, Message Clients
- Upload zone: drag-and-drop with document type and transaction assignment
- Active Transactions table: client, property, type, amount, status with View action
- Activity feed sidebar: real-time event stream from activity log
- Full supporting artifacts (validation schema, test scenarios, rollout, metrics, risks)
