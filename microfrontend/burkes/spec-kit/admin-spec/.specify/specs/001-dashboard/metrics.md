# Success Metrics: Dashboard (001)

| KPI | Target | Alert |
|-----|--------|-------|
| Dashboard load time (p50) | < 1.5s | > 3s |
| Dashboard load time (p99) | < 3s | > 5s |
| KPI data freshness | < 30 seconds | > 2 minutes |
| Quick Management tile click-to-action | < 500ms | > 1s |
| Pending approvals render | < 200ms | > 500ms |
| Activity feed render | < 200ms | > 500ms |
| Admin situational awareness | < 30 seconds to full overview | > 60 seconds |

## Success Definition
Dashboard is successful when for 30 days post-GA all KPIs sustained, zero critical bugs, admin can identify all pending items within 30 seconds, and support tickets < 1%.
