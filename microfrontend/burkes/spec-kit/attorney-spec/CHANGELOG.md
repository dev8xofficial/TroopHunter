# Changelog — Attorney Portal Spec-Kit

All notable changes to the spec-kit are documented in this file.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

---

## [1.0.0] — 2026-04-12

### Added

- **Foundation Spec (000)**: Design tokens, navigation, session context, activity log contract, modal system
- **Dashboard Spec (001)**: KPI stat cards, asset split reviews, client transactions table, activity feed, quick actions, upcoming deadlines
- **Transactions Spec (002)**: Transaction list, filtering, tabbed views (All/Pending/Divorce/Completed), search
- **Documents Spec (003)**: Document review, approval, rejection, upload, tabbed views, summary sidebar
- **Clients Spec (004)**: Client profiles, Add Client modal, Client Detail modal, messaging, role permissions
- **Verification Spec (005)**: Verification panels, progress steps, verify/flag workflow, checklist, report generation
- **Constitution**: 7 core principles, actor matrix, verification lifecycle, reference data, design constraints
- **Templates**: 10 template files for specs, plans, tasks, changelogs, and supporting artifacts
- **Supporting Artifacts**: Complete changelog, validation-schema, test-scenarios, rollout, metrics, and risks for all 6 features
- **Governance**: STANDARDS, ARCHITECTURE, GLOSSARY, FAQ, ROADMAP, CONTRIBUTING, GOVERNANCE, CODE_OF_CONDUCT, SPEC-DRIVEN
- **GitHub Infrastructure**: CODEOWNERS, PR template, issue templates, CI workflows, Copilot prompts
- **Global Schemas**: spec-structure.json, activity-log-event.json, transaction-model.json
- **Decision Records**: ADR-001 through ADR-005
- **Research**: User personas
