# Success Metrics: Foundation (000)

| KPI | Target | Alert |
|-----|--------|-------|
| Page load time (p50) | < 1s | > 2s |
| Navigation switch time | < 100ms | > 300ms |
| Modal open/close time | < 150ms | > 500ms |
| Activity log write latency | < 200ms | > 500ms |
| Session context resolve | < 500ms | > 1s |

## Success Definition
Foundation is successful when all screen transitions, modals, and activity logging meet targets for 30 days post-GA.
