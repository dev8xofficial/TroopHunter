# Web Designer with experience in Bootstrap and Chatbots — Job Posting

## Section A — Role Summary

asKId is an AI chatbot designed for children, helping them ask questions in a safe, age-appropriate environment while providing a parent/teacher perspective. The client seeks an expert web designer to polish and improve the user experience (UI/UX) of their existing Bootstrap-based website (www.askid.de). The primary outcome is to deliver responsive desktop and mobile designs that look trustworthy to parents/teachers and friendly to children, without requiring a complete frontend rebuild or heavy custom CSS.

## Section B — Responsibilities & Outcomes

- Design a polished landing page for asKId.
- Design the chatbot interface page.
- Build responsive UI layouts for both mobile and desktop views.
- Refine visual aspects including spacing, hierarchy, typography, buttons, cards, and overall consistency.
- Ensure the design is realistic and implementable strictly within Bootstrap components.
- Suggest style improvements to the existing style guide (www.askid.de/style-guide).

## Section C — Requirements & Qualifications

### Technical Constraints & Experience
- Extensive experience with Bootstrap-based web design.
- Proven experience with responsive UI/UX landing page design.
- Experience with SaaS, edtech, or child-friendly software products.
- Experience with chatbot or conversational layouts.
- Fluent English language level.

### Application Questions & Deliverables
- Figma, Adobe XD, or similar design proposals showing both desktop and mobile versions.
- Examples of Bootstrap-based websites/apps previously designed.
- One actionable idea for improving the current asKId homepage.
- Clear description of how the candidate avoids custom CSS overrides and stays aligned with standard Bootstrap classes.
