### REM, WalletOn and all WDI Applications — Privacy Policy

WDI believes in giving users absolute control over their private data, enabling them to be SELF-SOVEREIGN.

### Collection and Use of Non-Personal Information

WDI collects non-personal data that does not permit direct association with any specific individual. Examples include:

- Customer activity on WDI Cloud & App services — aggregated to improve usefulness and identify popular areas.

### Disclosure for Contact Lists and Images

The REM ID and WDI REM Play are Sovereign apps that store data locally on the user's device, inaccessible to third parties including the app developer. Principles applied:

- **Data minimization** — only data necessary for app function is collected.
- **Consent** — users must explicitly consent to data collection.
- **Transparency** — users receive clear information about data use.
- **Data security** — data is stored securely and protected from unauthorized access.

User data resides solely on the device and is never shared with WDI or any third party. Uninstalling the app instantly and permanently deletes all data. WDI retains no backups or copies.

WDI uses W3C standards and principles to implement self-sovereign identity for its REM ID app. Proprietary algorithms may supplement where standards are incomplete.

### Location-Based Services

WDI and partners may collect precise location data (GPS, Bluetooth, IP address, Wi-Fi hotspot, cell tower) to provide location-based services. Unless consent is given, data is collected anonymously and not personally identified.

### REM ID — Android App Deployment Guide (Sideloading)

For users without access to app stores, the REM ID APK can be installed via sideloading.

### Step-by-Step Guide

#### 1. Obtain the APK File

- Download directly from https://wdi.net/rem/ using the device's browser.
- Transfer from PC via USB cable (File Transfer mode), cloud storage (Google Drive, Dropbox), or peer-to-peer sharing apps.

#### 2. Enable Installation from Unknown Sources

Android blocks unknown-source installs by default. Grant permission as follows:

**Android 8.0 (Oreo) and newer:**
1. Go to Settings.
2. Navigate to Apps → Special app access → Install unknown apps.
3. Select the app used to open the APK (browser or file manager).
4. Toggle "Allow from this source" to ON.

**Android 7.0 (Nougat) and older:**
1. Navigate to Security (or Lock screen and security).
2. Toggle "Unknown sources" to ON.

#### 3. Locate and Install the APK

- Open a file manager and navigate to the Downloads folder.
- Tap the downloaded .apk file.
- Tap "Install" when prompted and wait for completion.
- Tap "Open" to launch or "Done" to finish.

#### 4. Security Best Practice

After installation, revoke the "Allow from this source" permission to maintain device security.

## 27 — REM vs. Traditional Credential Platforms

REM ID offers distinct advantages over traditional DC platforms such as Credly and Accredible:
