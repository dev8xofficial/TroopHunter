# Full Stack Developer for Logistics SaaS — RideIt LLC — Job Posting

## Role Summary

RideIt is a rural transportation and mobility company based in North Carolina preparing to launch a custom-built dispatch, reservation, and tracking platform initially focused on microtransit operations. The hired developer (or small team) will build a lean but scalable MVP suitable for client demonstrations, pilot programs, and early operational deployments. The platform is intentionally architected around generic "jobs" and "resources" rather than hardcoded transportation terminology so the same backend infrastructure can later support hospital valet/transport, shuttle operations, delivery workflows, and other reservation/dispatch-based verticals. An existing third-party dispatch platform is available to demonstrate desired workflow concepts during interviews.

## Responsibilities

- Build and deploy the backend API and core infrastructure covering reservation/job creation, scheduling, dispatching, real-time GPS tracking, ETA calculations, status updates and notifications, service zone/geofencing, user/account management, and scalable multi-tenant/white-label-ready architecture.
- Develop a web-based admin/operator dashboard with real-time map view, manual dispatching, driver/resource management, geofencing management, scheduling, trip status monitoring, basic reporting/analytics, and client configuration settings.
- Build a driver/worker mobile app supporting login/auth, online/offline toggle, assignment acceptance, navigation integration (Google Maps preferred), job start/complete flows, real-time GPS sharing, and basic earnings/trip history.
- Build a customer booking interface (web-first MVP) covering reservation creation, pickup/drop-off selection, scheduled rides, ETA/tracking visibility, and notifications.
- Implement security best practices: secure auth and RBAC, HTTPS across all APIs and web/mobile, encrypted password storage, secure cloud hosting, database backup/recovery, audit logging for admin/operational activity, and secure handling of GPS/location and user data.
- Maintain full source code access via GitHub or GitLab throughout development; deliver all custom code and deliverables as RideIt LLC property upon completion.

## Requirements
