# Website Updates for Deaf Multicultural Counseling (DMC)

**Budget:** $125 Fixed Price

Website:
https://www.deafmulticulturalcounseling.com

Deaf Multicultural Counseling (DMC) is seeking a website developer to make several updates to our existing website. We recently launched the website and are looking for someone who can help us with these updates and potentially provide ongoing support as our practice continues to grow.

## Project Scope

### 1. Add Two Team Member Profiles

Add the following team members to the website:

- Andre Robinson
- Arsalan Khan

Updates include:

- Upload headshots
- Add names, credentials, and titles
- Add bios
- Add areas of support (if applicable)
- Update team listings and profile cards
- Ensure consistency with the existing website design
- Verify mobile and desktop responsiveness

### 2. Create a Client Feedback Page

Create a new Client Feedback page based on the provided content and form from DMC.

The page should include:

- Feedback category selection
- Written feedback section
- Preferred feedback method options
- Follow-up preference options
- Optional name and email fields
- Confidentiality statement
- Confirmation/success message after submission

### 3. Web3Forms Integration

DMC currently uses Web3Forms on the website.

The Client Feedback page should:

- Use our existing Web3Forms setup
- Route submissions to the designated DMC email address
- Match the current website design and user experience
- Be mobile-friendly and responsive
- Be fully tested before deployment

### 4. Testing and Deployment

Before deployment:

- Test all new pages and forms
- Verify mobile responsiveness
- Verify desktop responsiveness
- Check links and navigation
- Confirm successful form submissions and email delivery
- Deploy updates to the live website

## Requirements

- Experience updating existing websites
- Experience with website forms and integrations
- Strong attention to detail
- Clear communication
- Ability to follow an existing design system
- Comfortable making revisions if needed

## Access

Access to the website repository, hosting, analytics, and related accounts will be provided after contract acceptance.

## Deliverables

- Two new team member profiles added
- Client Feedback page created and functional
- Web3Forms integration completed and tested
- Mobile and desktop layouts verified
- Updates deployed to the live website

## Timeline

**Preferred completion by Friday, June 19, 2026.**

Please indicate if you anticipate needing additional time.

## When Applying

Please include:

1. Your estimated timeline
2. Relevant experience
3. Examples of similar work (if available)
4. Any questions you may have about the project

Preference will be given to developers interested in providing ongoing website support for future DMC updates.
